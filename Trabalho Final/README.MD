# Sistema de Gerenciamento de Estacionamento

Projeto desenvolvido para a disciplina de **Banco de Dados II — IFTM Campus Patrocínio**.

O sistema foi desenvolvido para facilitar o controle de **clientes, veículos, vagas e movimentações de entrada e saída** de um estacionamento.

## Tecnologias

- Java
- MySQL
- GitHub

O projeto utiliza **chaves estrangeiras, operações de CRUD, View, Trigger e controle de permissões** para organizar e gerenciar os dados do sistema.
